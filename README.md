## المبادئ المعروضة

- **ترحيل ذرّي** — الفاتورة ومخزون السيارة وخزينة المندوب والقيد في معاملة واحدة
- **بلا اتصال أولًا** — يوم كامل بلا شبكة ثم مزامنة بلا فقد ولا تكرار
- **FEFO** — الأقرب انتهاءً يخرج أولًا، ومنع بيع المنتهي أو المحجور
- **فصل المهام** — لا يجمع مستخدم واحد الطلب والاعتماد والتنفيذ
- **لا حذف بعد الترحيل** — التصحيح بمستند عكسي مرتبط
- **عربي RTL أصلي** — لا واجهة مترجمة

## تقني

صفحة واحدة مستقلة. لا إطارات عمل، لا اعتماديات، لا طلبات شبكة.
خط **تجوال** مدمج داخل الملف (٨ أوزان، ٧٧ كيلوبايت) — يعمل بلا إنترنت.
الألوان مستخرجة من شعار الشركة.
HTML + CSS + JavaScript خالص. تدعم الوضعين الفاتح والداكن، ومتجاوبة مع الجوال.

```bash
git clone https://github.com/slamony702-crypto/cashvan-erp-prototype.git
cd cashvan-erp-prototype
# افتح index.html في المتصفح
```
